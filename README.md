# Character Moods / Fetish Manager (v1.2.0)

> Модуль управления предпочтениями, ролевыми динамиками и особыми чертами персонажей для SillyTavern.
> Гибкая настройка контекстных триггеров, сюжетов и промпт-инъекций. `(⁠⌐⁠■⁠_⁠■⁠)`

---

## Что нового в версии 1.2.0

* **Новая категория «Табу и Сюжетные Роли» (`taboo`)**: Добавлены глубокие поведенческие динамики для отыгрыша — срыв целибата, религиозные обеты, исповедь и покаяние, развращение праведника, двойная жизнь и шантаж.
* **Расширение структуры (8 категорий)**: База полностью переработана и разделена на 8 тематических блоков для более точной навигации.
* **Понятные пояснения к терминологии**: Для сложных, редких и медицинских понятий (*Абазиофилия*, *Форнифилия*, *Окулолингус* и т.д.) в интерфейсе добавлены расшифровки в скобках `(⁠・⁠_⁠・⁠;⁠)`.
* **Оптимизация системного промпта**: Промпты ролевых табу переписаны под контекстное поведение персонажа, а не сухие описательные теги.

---

## Функциональные возможности

* **Интенсивность влияния**: Регулировка степени проявления черт — от едва заметных намёков до ключевого элемента сцены.
* **Вероятностный генератор**: Настройка шанса срабатывания (от 10% до 100%) на каждый ответ ИИ.
* **Контекстные фильтры**:
* *Минимальный объём истории*: задержка активации до достижения заданного количества символов в чате.
* *Кулдаун*: фиксированный пропуск N сообщений после каждого срабатывания.
* *Анализ вводных данных*: проверка последнего сообщения пользователя на наличие ключевых слов.


* **Умный рандомизатор**: Автоматический выбор заданного количества элементов с опцией гарантии «по одному из каждой категории».
* **Пользовательские элементы**: Возможность добавлять собственные пресеты с уникальными инструкциями прямо из UI.
* **Адаптивный интерфейс**: Перетаскиваемая панель управления, мобильная плавающая кнопка и интеграция в стили темы SillyTavern.

## Установка

### Способ 1: Через интерфейс SillyTavern

1. Скопируйте ссылку на репозиторий:
`[https://github.com/miatriX456/Character-Behavior-Extension-for-SillyTavern-fetish-](https://github.com/miatriX456/Character-Behavior-Extension-for-SillyTavern-fetish-)`
2. В SillyTavern перейдите в раздел **Extensions** → **Install Extension**.
3. Вставьте скопированную ссылку и нажмите **Install**.

### Способ 2: Вручную

Склонируйте или распакуйте репозиторий в директорию:

`SillyTavern/public/scripts/extensions/third-party/fetish-manager`

## Принцип работы

Перед генерацией ответа модуль формирует системную инструкцию (`IN_CHAT`) и внедряет её в текущий контекст.

```
+--------------------------+
|  Проверка фильтров       | -> (Длина контекста / Кулдаун / Ключевые слова)
+--------------------------+
             |
             v
+--------------------------+
|  Бросок кубика (1d100)   | -> (Сравнение с уставленным % шанса)
+--------------------------+
             |
    +--------+--------+
    |                 |
[Успех]           [Пропуск]
    |                 |
    v                 v
Инъекция промпта   Обычный ответ
с параметрами      без изменений
    |                 |
    +--------+--------+
             |
             v
+--------------------------+
|  Генерация ответа ИИ     | `(⁠￣⁠ω⁠￣⁠)`
+--------------------------+

```

## Конфигурация фильтров

| Параметр | Назначение |
| --- | --- |
| **Мин. длина истории** | Блокирует срабатывание, пока суммарный объём текста в чате меньше N символов. `0` — отключено. |
| **Кулдаун** | Принудительно пропускает N сообщений после последнего успешного срабатывания. `0` — отключено. |
| **Ключевые слова** | Активирует генерацию только при наличии в последней фразе пользователя определенных слов-триггеров. |
